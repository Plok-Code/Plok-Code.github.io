En savoir plus sur le programme

Le programme est composé de 15 projets professionnalisants (~1 608 heures au total). Voici concrétement ce que je vais y construire, projet par projet :

  1. Découvrez le métier d'AI Engineer (14h) : cadrage du parcours, planning, appropriation des outils d'apprentissage.
  2. Requêtez des services IA (40h) : exploitation de modèles pré-entraînés pour analyser la mode en ligne d'une entreprise de vêtements (Python, Pandas).
  3. Anticipez les besoins en consommations de bâtiments (40h) : aider une grande ville à atteindre la neutralité carbone via Machine Learning supervisé (Sk-learn).
  4. Classifiez automatiquement des informations (50h) : modèle de classification supervisée, nettoyage, transformation, entraînement et évaluation (Sk-learn, SQL, NoSQL).
  5. Déployez un modèle de Machine Learning (40h) : passage en production avec une infrastructure de données robuste et sécurisée.
  6. Initiez-vous au MLOps (1/2) (50h) : classification binaire sur données bancaires, versioning des modèles avec MLflow, gestion overfitting / underfitting.
  7. Concevez et déployez un système RAG (60h) : Retrieval-Augmented Generation fonctionnel avec LangChain + Mistral + base vectorielle Faiss, exposé via API.
  8. Confirmez vos compétences en MLOps (2/2) (45h) : dashboard d'explicabilité d'octrois de crédit, déploiement cloud, API custom, étude du drift (FastAPI, Docker, CI/CD).
  9. Réalisez le cadrage d'un projet IA (45h) : présentation devant un COMEX, prototype, analyse de risques, gouvernance, conduite du changement.
  10. Labellisez et appliquez des approches semi-supervisées en traitement d'images (40h) : premier projet de Deep Learning Vision (CNN, semi-supervisé).
  11. Entraînez votre agent RL (80h) : agent de Reinforcement Learning dans un environnement de jeu, construit avec TensorFlow + PyTorch, exposé via API et dashboard.
  12. Extrayez des données multimodales de sites web (80h) : pipeline complet d'extraction, transformation et orchestration (texte + image) pour entraîner un détecteur de fake news.
  13. Mettez en place un Agent IA (80h) : POC d'agent IA pour l'apprentissage des échecs, avec modèle adapté aux besoins métier.
  14. Finetunez votre propre LLM (80h) : POC d'agent conversationnel de triage médical via fine-tuning, automatisation du déploiement, évaluation de l'infrastructure.
  15. Réalisez le portfolio d'AI Engineer (60h) : projet technique final, audit d'une solution data, appui stratégique à la décision, contrôle délais / coûts / livrables.

Technos couvertes Python, SQL, PostgreSQL, PySpark, Airbyte, Kestra, Redpandas, Pandas, Sk-learn, MLflow, BentoML, FastAPI, Docker, Streamlit, LangChain, Mistral, Faiss, TensorFlow, PyTorch, Great-Expectations, Pydantic, Pytest, Git, GitHub, CI/CD, Jupyter Notebook.
